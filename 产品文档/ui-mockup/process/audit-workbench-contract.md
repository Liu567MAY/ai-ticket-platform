# Direction contract — 老师审核工作台（学分置换 AI 审核协同平台）

构建目标：产品文档/ui-mockup/audit-workbench.html（单文件静态原型，code-led，无图像生成能力故无 comp 轮）。
种子延续：f22b912d 方向轮「安灯看板」世界的收敛与适配；用户本轮简报为精确指定（三栏比例/树形导航/规则卡片/场景化按钮/配色），按 new-work"精确请求直接 shaping"执行。

THESIS: 审核工作台是老师的复核桌面，不是监控台。信息三层律是本界面的宪法——第一层业务事实（谁申请的、交了什么），第二层 AI 判断（逐规则结论与问题清单），第三层技术执行（Run/Node/Tool/Token，默认隐藏，只从"查看执行详情"抽屉进入）。主界面零终端元素、零日志条、零步骤状态条；旧版深色 runlog 一类组件永久退出主工作面。

OWN-WORLD: 白面板 + 浅灰地 #F5F6F8 + 发丝线 #E4E7EB；主色机构蓝 #24518F（沿用）；语义状态色：通过绿 #1F7A4D / 不通过红 #C13A2B / 需补材料橙 #C2610E（文字 #A34E08）/ 需人工复核灰蓝 #5A6472。中文系统字栈 + Consolas（只出现在编号与抽屉内）；圆角 6/8px；阴影仅 1px 柔影。安灯灯语法保留为唯一状态语言（实心灯=终态、闪烁=进行中、空心=未开始），"橙色=等我操作"是全页行动语义。

STORY: 老师 5 秒内回答四问——谁申请的（树+标题）、交了什么（材料列表）、AI 哪几条没过（问题清单+规则灯）、我该点哪个按钮（随业务状态出现的唯一主按钮）。学生的技术细节永远不可见；老师的技术细节一键可得但不打扰。

FIRST VIEWPORT: 顶栏（灯点品牌标 + 工作台/申请管理/审核任务/Agent 运行记录 + 周老师·REVIEWER）之下三栏 280px/1fr/420px：左侧"审核任务"文件夹树（搜索框 + 日期 → 状态组（计数、语义色点）→ 学生叶子，展开/收起、选中高亮）；中间申请详情（标题"王五 - 学分置换申请" + 状态药丸、8 格元数据、"更多信息"折叠、提交材料列表含缺失材料虚线行，点击文件出预览浮层）；右侧"AI 审核结果"（结论横幅 → 问题清单 → 规则卡片列表（点击展开详情：问题/依据/规则要求/证据/置信度 + 确认判断/修改判断，修改为内联编辑并重算结论）→ 场景化操作按钮 → 审核历史 Run #1）。

FORM: 用户简报精确指定：三栏 20/50/30、文件夹树导航（IDE/文件管理器参照）、简洁状态规则卡片、问题清单独立成节、按钮随状态出现、Trace 入抽屉。签名交互 = 规则详情内联修改判断 → 结论与问题清单即时重汇总（PRD"修改即重新 Aggregate"决策的 UI 化）。演示数据覆盖四种老师视角状态（待复核×2 含全过与有问题、待最终审批、待补材料）与待AI审核/已通过/已驳回只读态。

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md 更新（主界面去控制台化 + 抽屉组件 + 橙色语义入系统）, and every shipping raster carrying its provenance.
